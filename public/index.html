SkillRise

Welcome to the SkillRise full-stack app. This site is served by the same Node.js backend that provides API endpoints.

API Endpoints

  • /blogs - Get all blogs
  • /health - Health check
  • POST /register
  • POST /login

Next steps

Deploy this app to a Node-friendly host such as Render, Railway, Fly.io, or Vercel (Serverless) with a MongoDB add-on.

Netlify does not host long-running Node servers directly, so use Render or Railway for the full backend + frontend deployment.
